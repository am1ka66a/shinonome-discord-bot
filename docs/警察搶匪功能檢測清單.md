# 警察／搶匪（通緝）功能檢測清單

給**所有測試人員**使用：請依序或依場景執行，並在「結果」欄打 ✓／✗ 或簡註。若與預期不符，請截圖並記錄時間、伺服器、指令與參與者 ID。

---

## 一、測前準備

| 項目 | 說明 |
|------|------|
| 人數 | 至少 **2 個真人帳號**（建議 3 個：警察、搶匪、被害人／路人） |
| 頻道 | 在**同一伺服器**、機器人可讀寫的頻道測試 Slash |
| 餘額 | 搶劫需雙方 **≥ 50,000** 東雲幣等既有規則；假釋需 **≥ 100,000**（見下） |
| 指令 | 確認已出現：`/role_choose`、`/wanted_status`、`/cop_hunt`、`/bail`、`/rob`、`/help` |
| 資料庫 | 正式機須已部署含 `role`、`wanted_*`、`in_prison`、`wanted_log`、`prison_records` 等欄位／表的版本 |

**假釋金常數**：`/bail` 需 **`100,000`** 東雲幣（與程式 `BAIL_COST` 一致）。

---

## 二、指令速查（測試對象）

| 指令 | 誰用 | 用途 |
|------|------|------|
| `/role_choose` | 所有人 | 切換 **警察 cop** 或 **搶匪 criminal**（選警察會清空通緝星與追捕計數） |
| `/wanted_status` | 自己 | **只有自己可見**（ephemeral）：陣營、通緝星、本輪是否可再被追、是否在獄、逮捕次數、最近搶劫紀錄 |
| `/cop_hunt` | 僅 **role=警察** | 指定通緝犯（成員或 ID），嘗試逮捕 |
| `/bail` | **在獄中**且餘額足夠者 | 繳假釋金出獄 |
| `/rob` | 所有人（在規則內） | 搶劫；僅 **搶匪身分** 成功搶劫會累積通緝與搶劫紀錄 |

## 三、基礎流程檢測

### A. 身分與說明

| # | 步驟 | 預期結果 | 結果 |
|---|------|----------|------|
| A1 | 帳號甲執行 `/role_choose` → **警察** | 成功 embed；說明含 `/cop_hunt` | |
| A2 | 帳號乙執行 `/role_choose` → **搶匪** | 成功 embed；說明含通緝／搶劫／`/bail` | |
| A3 | 甲、乙分別 `/wanted_status` | 甲顯示警察；乙顯示搶匪；通緝星可為 0 | |

### B. 搶劫與通緝（搶匪）

**前置**：乙為搶匪；丙為被害人，餘額 ≥ 50,000；搶劫冷卻與保護時間已過（或換帳號）。

| # | 步驟 | 預期結果 | 結果 |
|---|------|----------|------|
| B1 | 乙 **搶劫失敗**（或條件不符未成功） | 訊息無通緝升級文案；`/wanted_status` 星級不應因失敗而 +1 | |
| B2 | 乙 **搶劫成功** | 成功訊息可含通緝說明；乙 `/wanted_status` 通緝 **+1**（未滿 5 星時），且「本輪可追捕」應為可追狀態 | |
| B3 | 連續成功搶劫至 **5 星** | 滿星文案出現；再成功搶劫仍會重置「本輪追捕」相關邏輯（滿星後每次搶成功可再被追一次，依實作） | |
| B4 | 丁為 **平民**（未選搶匪）成功搶劫 | 成功訊息**不應**出現通緝升級（非搶匪不加星） | |

### C. 警察追捕

**前置**：乙為搶匪且至少 1 星、`wanted_hunted_count` 為 0（剛升星或剛搶成功後）；甲為警察。

| # | 步驟 | 預期結果 | 結果 |
|---|------|----------|------|
| C1 | 丙（非警察）執行 `/cop_hunt` 指定乙 | 拒絕：僅警察可用 | |
| C2 | 甲 `/cop_hunt` 指定 **無通緝** 的對象 | 提示無通緝 | |
| C3 | 甲 `/cop_hunt` 指定 **在獄中**對象（見 D 後測） | 提示已在監獄 | |
| C4 | 甲 `/cop_hunt` 指定乙（有星且本輪可追） | 出現成功或失敗 embed；失敗後乙 `/wanted_status` 顯示**本輪已嘗試**不可再追（至下次規則滿足） | |
| C5 | 追捕**成功**後 | 乙：`/wanted_status` 通緝 **0**、在獄、搶劫紀錄清空；甲餘額 **+**「乙最近五次搶劫成功總額」；乙被扣約 **40% 當下餘額**（沒收） | |
| C6 | 追捕**失敗**後 | 乙仍在外；通緝星不變；不可立即再對同星級同一輪重複追（至升星或滿星規則） | |

> 註：實際成功與否含隨機，可多測幾次或暫時用多帳互測紀錄。

### D. 入獄與假釋

| # | 步驟 | 預期結果 | 結果 |
|---|------|----------|------|
| D1 | 乙在獄中時執行 `/rob` | 拒絕：**無法在監獄搶劫** | |
| D2 | 乙餘額 **&lt; 100,000** 時 `/bail` | 提示餘額不足 | |
| D3 | 乙餘額 **≥ 100,000** 時 `/bail` | 扣 **100,000**；出獄成功訊息；`/wanted_status` 顯示不在獄 | |
| D4 | 乙**不在獄**時 `/bail` | 提示不在監獄 | |

### E. 切換身分（迴歸）

| # | 步驟 | 預期結果 | 結果 |
|---|------|----------|------|
| E1 | 通緝中的乙改 `/role_choose` → **警察** | 通緝星與追捕計數應 **清空**（實作為選警察時一併歸零） | |
| E2 | 甲（警察）改 `/role_choose` → **搶匪** | 可成功；不強制清通緝（僅選警察時清） | |

## 六、給非技術人員的一句話

- **搶匪**：搶成功會**加通緝**；**滿星或每輪**會影響警察能不能追你。  
- **警察**：用 `/cop_hunt` 抓人，成功可拿對方**最近五次成功搶劫的總和**，對方**入獄並被沒收一大筆錢**。  
- **所有人**：`/wanted_status` 看自己狀態；在獄用 `/bail`（**十萬**）出獄。

有問題請把**指令名、誰對誰做、當時大概餘額與通緝星**記下來回報。
