# 管理員發話 `/say`

限原有主機白名單使用，並保留 Discord 的「管理訊息」預設權限設定。
只可在目前伺服器內的文字頻道或討論串發送，操作結果只對操作者顯示。

- `text`：要發送的文字，最多 2,000 字。
- `channel`：目標文字頻道或討論串，選填。
- `image`：從裝置選取一張圖片附件，選填。支援純圖片或文字加圖片，保留暴雷標記。
- `reply_to`：要回覆的 Discord 訊息連結，或訊息 ID，選填。
- `preview`：預設開啟，先顯示私人預覽，120 秒內確認後才發送；設為 `false` 可直接發送。

文字和圖片至少提供一項。圖片不能超過目標伺服器的附件大小上限。

## 使用方式

1. 一般發話：選擇 `/say`，填入 `text`，需要時選擇 `channel`。
2. 發送圖片：在 `image` 上傳圖片，可搭配 `text`，也可只傳圖片。
3. 回覆訊息：對原訊息選擇「複製訊息連結」，貼入 `reply_to`。
   未填 `channel` 時會自動使用該連結的頻道；若有填，必須與連結相同。
4. 若使用純訊息 ID，會在 `channel` 指定的頻道尋找；未指定則使用目前頻道。
   複製訊息 ID 需要先開啟 Discord 的開發者模式。

預覽中可確認或取消；確認時會重新檢查權限和原訊息是否存在。
每次發送會記錄操作者、頻道、回覆對象、結果及新訊息 ID，不保存文字或圖片內容。

回覆會顯示 Discord 原生的回覆引用，且不自動提及原作者。
原訊息被刪除或無法讀取時會回報錯誤，不會改成一般發話。成功時會提供新訊息的連結。
機器人需有查看頻道、發送訊息，以及回覆時的讀取歷史訊息、附圖時的附加檔案權限；
討論串另需「在討論串中發送訊息」權限。

程式部署並完成 Slash 指令同步後，Discord 才會顯示新的選填欄位。
